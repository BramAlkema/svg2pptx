# Debugging Artifacts Archive

## Purpose
This directory contains debugging artifacts from development sessions, particularly focused on the DTDA logo debugging work that was performed during SVG processing optimization.

## Contents
- `dtda_logo*.svg` - Various iterations of DTDA logo files used for debugging
- `debug_dtda*.py` - Debugging scripts created for DTDA-specific issues
- `*_debug_report.*` - Debug output files and reports from troubleshooting sessions

## Archival Date
January 29, 2025

## Context
These files were created during intensive debugging sessions to resolve SVG processing issues. While no longer needed for active development, they preserve the debugging methodology and solutions discovered.

## Recovery
If these debugging artifacts are needed again:
```bash
# Files can be copied back to project root
cp archive/development-artifacts/debugging/filename.ext .
```
